## یادداشت‌های مطالعه

_Learn to Code with C_ برنامه‌نویسی را از راه C و برای مبتدی‌ها آموزش می‌دهد. Raspberry Pi به کتاب زمینه‌ی عملی می‌دهد و آن را از حالت انتزاعی بیرون می‌آورد.

بدون چنین زمینه‌ای، C یا زیادی آکادمیک می‌شود یا زیادی ترسناک. برنامه‌ی کوچکی که روی دستگاه واقعی اجرا می‌شود، بازخورد را ملموس نگه می‌دارد.

## ایده‌های مفید

### برنامه‌ی کوچک کافی است

در یادگیری C، برنامه‌ی کوچک بازی نیست؛ جایی است که جزئیات مهم دیده می‌شوند: type، شرط، حلقه، تابع، آرایه و ورودی/خروجی.

### سخت‌افزار کمک می‌کند

Raspberry Pi کد را به دستگاهی وصل می‌کند که خواننده واقعاً می‌تواند برنامه را رویش اجرا کند و تغییر دهد.

### اول اصول، بعد framework

یادآوری می‌کند که مهارت برنامه‌نویسی، پیش از آنکه به معماری برسد، از ایده‌های کوچک و روشن ساخته می‌شود.

## چرا نزدیک نگهش می‌دارم

نقطه‌ی شروع خوبی است برای آموزش‌دادن، مرور اصول، یا گرم‌شدن پیش از کار جدی‌تر embedded با C.
