## یادداشت‌های مطالعه

_Modern C for Absolute Beginners_ روی قفسه مانده، چون C هنوز چیزهایی را نشان می‌دهد که خیلی از زبان‌های سطح بالاتر پنهان می‌کنند: چیدمان حافظه، کامپایل، pointer، undefined behavior و هزینه‌ی هر abstraction.

در مهندسی امروز، C فقط زبان legacy نیست؛ راهی است برای ساختن مدل ذهنی دقیق‌تری از کامپیوتر.

## ایده‌های مفید

### حافظه ملموس می‌شود

در C حافظه دیده می‌شود. متغیر، آرایه، pointer، تخصیص حافظه و lifetime دیگر جزئیات مبهم پیاده‌سازی نیستند؛ بخشی از کارند.

### کامپایل را باید فهمید

ارزش دارد مسیر سورس تا executable را بفهمی. header، translation unit، linking و flagهای build همه روی برنامه‌ای که واقعاً اجرا می‌شود اثر می‌گذارند.

### سادگی لبه‌ی تیز دارد

C آن‌قدر کوچک است که بشود یادش گرفت، و آن‌قدر سخت‌گیر که نشود بی‌دقت با آن کار کرد. همین ترکیب از آن معلم خوبی می‌سازد.

## چرا نزدیک نگهش می‌دارم

راه خوبی برای برگشتن به systems programming است، بدون اینکه وانمود کنیم هر روز با C کار می‌کنیم.
