مالکیت state، مرز component و رفتار render، پایه‌های فهم React هستند. «React Key Concepts» نوشته‌ی ماکسیمیلیان شوارتزمولر، این مفهوم‌ها را کنار هم توضیح می‌دهد تا رابطه‌ی بین آن‌ها، فراتر از استفاده‌ی جداگانه از هر API، روشن شود.

## component و جریان داده

JSX، component، prop، state، effect، ترکیب componentها و جریان داده، موضوع‌های کتاب‌اند. این‌ها توضیح می‌دهند رفتار در کدام بخش قرار می‌گیرد و تغییر چگونه در اپلیکیشن پخش می‌شود.

روشن‌بودن مسئولیت‌ها محور کاربردی بحث است. component دور رفتار و ظاهر مرز می‌سازد. state به صاحب مشخص نیاز دارد و effect برای اتصال منطق render به سیستم بیرونی به کار می‌رود؛ استفاده از آن باید هدف روشن داشته باشد.

## یادگیری و تثبیت اصول

برای یادگیرنده‌ی React و توسعه‌دهنده‌ای که پیش از کار روی کد بزرگ‌تر، اصول را مرور می‌کند، مفید است. جزئیات وابسته به نسخه به مستندات فعلی React نیاز دارند. مدل روشن component و داده، گاهی پیش از اضافه‌کردن کتابخانه‌ی state یا لایه‌ی تازه، مسئله را حل می‌کند.
