در میکروکنترلر، حافظه و زمان مستقیماً وارد مسئله‌ی برنامه‌نویسی می‌شوند. «Freescale ARM Cortex-M Embedded Programming Using C Language» نوشته‌ی محمدعلی مزیدی و همکارانش، اصول C را به این شرایط سخت‌افزاری وصل می‌کند.

## برنامه‌نویسی دستگاه

کتاب به C در میکروکنترلرهای Freescale ARM Cortex-M می‌پردازد؛ از نقشه‌ی حافظه و registerهای نگاشت‌شده به حافظه تا interrupt و زمان‌بندی. توضیح یک register، بخشی از رابطی است که برنامه باید با آن کار کند.

مثال‌ها رابطه‌ی عملیات C و رفتار دستگاه را روشن می‌کنند. درستی برنامه شامل تولید مقدار در زمان مناسب هم هست. حافظه‌ی محدود و دشواری مشاهده‌ی وضعیت اجرا، اهمیت ساختار روشن را بیشتر می‌کنند.

## پیش‌نیاز و زمینه‌ی سخت‌افزاری

آشنایی با مقدمات C نقطه‌ی شروع مناسبی است. مثال‌های وابسته به دستگاه باید با راهنمای برد مورد استفاده تطبیق داده شوند. ارزش گسترده‌تر کتاب، دنبال‌کردن رفتار نرم‌افزار تا سطح سخت‌افزار است؛ روشی که به یک خانواده‌ی میکروکنترلر محدود نمی‌ماند.
